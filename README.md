# zzClockPlus (zz시계 후속)

Edge 540 / 840 / 1040 / 550 / 850 / 1050 / 1060 용 시계 + 온도 + GPS + 배터리 데이터 필드.
SDK 9.3.0, 타입 체크 Strict(-l 3)로 7개 기종 모두 빌드 확인.

## 화면
- 10필드 칸: 위 상태 줄(온도, GPS, 배터리 %, 배터리 아이콘), 아래 시:분
  - 오전/오후: 시계 위 (540/840은 높이가 부족해 상태 줄 왼쪽)
- 넓은 칸: 위 상태 줄, 아래 시:분:초, 시계 왼쪽에 A/M 세로 표시
- 낮은 넓은 칸(550/850의 420x60 등): 왼쪽 시:분, 오른쪽 상태
- 시계: 글자 간격을 좁히고(-0.03em, 콜론 0.20em) 좌우 여백 3%로 칸 폭에 맞춤
  10필드 칸 34 / 39 / 58 / 67px, 넓은 칸 33 / 47 / 63 / 80px (540 / 1040 / 550 / 1060)
- 아이콘: zzTimerFont 글리프 사용
  - GPS: 0단계 주황 사선, 1~4단계는 회색 막대 위에 단계만큼 칠함 (Activity.Info.currentLocationAccuracy)
  - 배터리: 충전 중 / 잔량 5단계, 15% 미만 빨강, 30% 미만 노랑, 그 외 초록
- 영하 온도 표시 (상태 줄 크기는 "-12C", "100%" 기준으로 계산)

## 단위 숨김 모드 (설정 "단위 표시" 끔)
- C, % 단위와 오전/오후 표시를 숨기고, 10필드 칸 상태 줄을 칸 폭에 맞춰 키움
- 보통 값(2자리) 기준 큰 폰트: 540/840 16, 1040 22, 550/850 32, 1050/1060 37px
- "-12", "100"처럼 긴 값이라 폭을 넘으면 자동으로 15 / 17 / 26 / 29px 폰트 사용 (값이 바뀔 때만 확인)

## 경고
- GPS: 기록 시작/재개 후 30초 동안 GPS 미수신(0~1단계)이면 빨간 배경이 1초 간격으로 깜빡임
- 마일리지: 활동의 첫 출발 후 30초 동안, 교체 주기를 넘은 항목이 있으면 파란 배경

## 마일리지
- 활동 리셋(저장 또는 삭제) 때 이번 거리를 6개 항목(value1~6)에 더함
- 단위는 기기 거리 단위(km/mi)를 따름 (기존 버전은 온도 단위를 따르던 문제 수정)
- 설정 이름(label/limit/value 1~6)은 기존 zz시계와 같음

## 온도
- 백그라운드 서비스가 5분마다 Sensor.getInfo().temperature를 읽어 Storage "sensorTemp"에 저장 (기존과 동일)
- 권한: Background, Sensor (GPS는 Activity.Info를 써서 Positioning 권한 불필요)

## 설정
버전 / 시간 형식(시스템, 12, 24) / 온도 단위(시스템, C, F) / 단위 표시(기본 표시) / GPS 경고 / 소모품 알림 / 소모품 6개 항목

## 업로드 전
- manifest.xml application id는 임시 UUID. 기존 zz시계를 업데이트한다면 기존 앱의 UUID와 개발자 키를 사용할 것.
